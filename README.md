# Delivery-System

This project is a system to keep track of deliveries and make them organized, easy to access, and easy to use. This system is essential as it makes it an efficient way to digitally keep track of orders without having to physically keep it on a piece of paper. It solves numerous problems, such as not being able to access the orders anywhere, losing the order sheet if it was on a physical copy, and being difficult to use in a spike of orders.

Delivery System Tips
1.) Sketch out your system using a class diagram
2.) Use a strict order status flow

Additionally, the delivery system program requires the following resources:
- CPU and Memory (RAM)
- Network
- Database
- Security & Access control
